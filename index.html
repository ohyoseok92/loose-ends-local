Loose Ends

A local AI that rereads Markdown notes and turns forgotten promises into a source-linked checklist. It merges duplicate reminders and leaves the original notes untouched.

Recorded demo

This 16-second replay uses synthetic notes and the verified output of a real local Qwen2.5-Coder run.

Run it locally

ollama pull qwen2.5-coder:7b-instruct-q4_K_M
python loose_ends.py examples/notes --output demo-report.md
